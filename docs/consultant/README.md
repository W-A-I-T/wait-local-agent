# Consultant and Microsoft Platform Lane

This lane documents the local-first consultant surfaces: discovery, provider-
neutral blueprints, architecture projections, governance, evaluations,
Power Apps/Power Automate planning, and Power Platform source packaging.

These surfaces produce inspectable local artifacts and reviewable plans. A
Power Platform package is an official YAML source package for a later local PAC
operation; it is not provider import, live verification, or deployment.
Microsoft, M365, and Power Platform are implementation targets governed by the
WAIT Local Agent runtime, not the product identity.
