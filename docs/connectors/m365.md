# Microsoft 365 and Entra

The Microsoft Graph connector provides bounded user, group, license,
mail-folder, message-metadata, and Intune managed-device reads. Approved
actions cover selected user lifecycle, group membership, license, session,
mailbox-settings, message, and managed-device operations; wipe, send, and
permanent deletion are not exposed.

The built-in [Microsoft Cloud and Endpoint Administrator pack](microsoft-admin.md)
extends the read and diagnostic surface with service health, Secure Score,
sign-ins, Conditional Access, risky users, Intune applications and compliance
policies, Autopilot identities, and Defender XDR incidents and alerts. It
reuses the same credential and probing boundary and does not add an independent
write engine.

```text
WAIT_M365_GRAPH_BASE_URL=https://graph.microsoft.com/v1.0
WAIT_M365_ACCESS_TOKEN=
WAIT_M365_PAGE_SIZE=25
WAIT_ALLOW_HTTP_PROBING=true
```

Every write requires an explicit target, the existing approval flow, probing,
and `WAIT_ALLOW_WRITE_ACTIONS=true`; temporary passwords are resolved only
from the local vault at execution time. Validate and read with the `m365-*`
connector commands. Fixture/mock coverage is available; live Graph
verification is not claimed.
